# AI Content Marketing using UGC Ads

This project demonstrates the use of Prompt Engineering to generate high-converting User Generated Content (UGC) advertisements for social media marketing.

- Brand Brief
- Prompt Version 1
- AI Output Version 1

## Objective

To create AI-powered UGC marketing assets using structured prompts while improving content quality through prompt refinement.
